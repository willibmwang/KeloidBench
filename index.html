The central finding

Programs outperform isolated markers when cohorts change.

Fibroblast program features transfer across public tissue cohorts substantially better than singular marker genes.

The transferable subset reaches approximately 0.92 LOSO macro F1. Pooled held-out accuracy is approximately 0.84. Difficult profiles and a known non-transferable platform remain visible rather than being hidden by the average.

Algorithm

Expression in. Auditable evidence out.

The generative component is downstream of deterministic inference: it explains an evidence packet but cannot change the probability, class, confidence rule, or transfer warning.

  1. 01

    Normalize

    Standardize HGNC symbols, collapse duplicates, and check program gene coverage.

  2. 02

    Program scoring

    Compute within-sample percentile-rank contrasts for versioned positive and reference gene sets.

  3. 03

    Classify

    Align the program feature vector to a frozen linear decision function and derive P(keloid).

  4. 04

    Abstain

    Withhold the class when maximum class probability falls below the fixed confidence policy.

  5. 05

    Explain

    Package scores, contributions, QC, and provenance into an immutable evidence record.

Biological context & provenance

Images explain the problem. Transcriptomes drive the model.

Clinical photography is shown only to ground the phenotype. KeloidBench does not analyze images; it operates on public, de-identified expression profiles.

Profiles trace back to their public studies

Select a source to open its original publication or GEO record.

Use boundary

A research benchmark, not a clinical diagnostic.

Public transcriptomic studies vary in platform, tissue composition, preprocessing, ancestry, and sampling design. Predictions should be interpreted as research-triage outputs, with cohort transferability and abstention reviewed before any biological conclusion.
